# Sources: Contoso Regional Health (fictional) Zero Trust reference set

> **Reference work.** Fictional scenario built for a public portfolio. Not deployed in, derived from, or describing any employer environment. Not professional advice.

This is the consolidated source list for the HIPAA Security Rule NPRM research note (`hipaa-security-rule-nprm-status.md`) and for the product, framework, and regulatory facts verified for the architecture set. Every source shows its publisher, URL, the date it was checked, and a quality label. Sources cited in other documents of this set and not listed here appear in those documents' own Sources sections.

**Quality labels.**

- **Primary:** the issuing authority, or the author of the thing described, read directly. Regulators, standards bodies, the Federal Register, and vendor documentation about the vendor's own products and licensing count as primary. Vendor documentation is primary only for the vendor's own product behavior, status, and licensing.
- **Primary (third-party copy):** a primary document read from a copy that someone other than its publisher hosts, because the publisher's own copy could not be read. The row names the host, and the copy's integrity rests on that host.
- **Secondary:** reporting or analysis by someone else.
- **Unverified:** the source could not be read when checked (for example, HTTP 403), so the claim it is cited for rests on a search snippet or a secondary report and must be rechecked before anything relies on it.

**Dates.** "Date checked" is the day the source was read for this set. For Microsoft Learn pages, the notes give the page's own "updated" date as shown at check time, because preview and general availability status changes often.
