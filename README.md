# Zero Trust Reference Architecture for a Regional Health System

> **Reference work.** Fictional scenario built for a public portfolio. Not deployed in, derived from, or describing any employer environment. Not professional advice.

Work in progress. This repository will hold a Zero Trust reference architecture for a fictional regional health system, a threat model of that architecture, a detection pack that answers the threat model, a HIPAA and NIST CSF 2.0 compliance crosswalk, and a sourced research note on the proposed HIPAA Security Rule update. Content will be added as it is completed and reviewed.
